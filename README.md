# Grafika komputerowa i komunikacja człowiek-komputer

### Laboratoria 2026/2027

Witajcie w repozytorium przedmiotu **Grafika komputerowa i komunikacja człowiek-komputer**.

To właśnie tutaj będziecie przesyłać rozwiązania zadań laboratoryjnych. Wszystkie prace oddajemy za pomocą **Pull Requestów (PR)** na GitHubie.

## Jak oddać laboratorium?

1. **Utwórz Fork repozytorium** – skopiuj repozytorium na swoje konto GitHub.

2. **Dodaj rozwiązania** – umieść pliki z kodem źródłowym w folderze odpowiadającym danemu laboratorium.

3. **Utwórz Pull Request** – zaproponuj dodanie swoich rozwiązań do głównego repozytorium (gałąź `main`).

4. **Nadaj tytuł PR** według schematu:

   `Laboratorium X - Imię Nazwisko`

   Na przykład: `Laboratorium 2 - Jan Kowalski`. W miejscu `X` wpisz numer laboratorium od 2 do 7.

5. **Poczekaj na automatyczne oznaczenie PR** – GitHub Actions przypisze odpowiedni **Milestone**, np. `Laboratorium 2`, a GitHub doda prowadzącą jako reviewera dzięki plikowi CODEOWNERS. Nie musisz wybierać ich ręcznie.

   Jeśli PR jest oznaczony jako **Draft**, kliknij **Ready for review**, gdy rozwiązanie będzie gotowe. Dopiero wtedy prowadząca otrzyma prośbę o review.

> ⚠️ **Ważne:** Każde laboratorium powinno mieć osobny Pull Request. Poprawny tytuł jest wymagany do automatycznego przypisania Milestone. Jeśli oznaczenie się nie pojawi, sprawdź wynik workflow w zakładce **Actions** i zgłoś problem prowadzącej na Discordzie.

## Potrzebujesz pomocy?

Jeśli napotkasz problem z zadaniem lub przesłaniem rozwiązania, napisz na Discordzie.
